# قهوتي — Ghawati Pro ☕

نسخة احترافية أولية لمشروع "قهوتي" تشمل:
- Login + Sessions
- Roles: Admin / Runner / Employee
- طلبات القهوة
- شاشة الطلبات للـ Runner
- إحصائيات
- عجلة الحظ
- باريستا ذكي (تقرير تحليلي محلي)
- إدارة المستخدمين
- SQLite Database
- كلمات المرور محفوظة كـ bcrypt hash
- تصميم RTL متجاوب مع الجوال

## التشغيل
1. ثبتي Node.js (الإصدار 18 أو أحدث).
2. افتحي Terminal داخل مجلد المشروع.
3. شغلي:
   `npm install`
4. ثم:
   `npm start`
5. افتحي:
   `http://localhost:3000`

## حسابات التجربة

## مهم قبل التسليم
- غيّري SESSION_SECRET في بيئة النشر.
- استخدمي HTTPS في الاستضافة.
- اربطي تقرير AI الحقيقي بمزود LLM إذا كان مطلوباً من الدكتور حرفياً؛ حالياً التقرير الذكي يعمل كنسخة تجريبية بدون API key.
- قاعدة البيانات `ghawati.db` تنشأ تلقائياً عند التشغيل.

## النشر
يمكن نشر المشروع على أي استضافة تدعم Node.js + SQLite، أو نقل قاعدة البيانات إلى خدمة PostgreSQL عند استخدام استضافة لا توفر تخزيناً دائماً.
